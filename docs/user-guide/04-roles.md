# 4) الأدوار والصلاحيات

عند إضافة عضو إلى منشأتك، تحدّد له **دوراً** يضبط ما يمكنه عمله. الصلاحيات **مفروضة على مستوى قاعدة البيانات** (RLS) — لا مجرد إخفاء أزرار — فلا يمكن لأي دور تجاوز حدوده.

## القدرات الخمس
- **الاطّلاع (view):** قراءة بيانات المنشأة.
- **إدارة البيانات (manage_data):** إنشاء/تعديل العقارات والوحدات والمستأجرين والملّاك والعقود والاستيراد.
- **إدارة المالية (manage_finance):** سندات القبض، الدفعات، الفواتير، الإشعارات الدائنة/المدينة، توريدات الملّاك.
- **إدارة الفريق (manage_team):** دعوة الأعضاء وتحديد أدوارهم ونطاقاتهم.
- **إدارة الاشتراك (manage_billing):** الخطط، الدفع، والتجديد التلقائي.

## المصفوفة
| الدور | اطّلاع | بيانات | مالية | فريق | اشتراك |
|---|:--:|:--:|:--:|:--:|:--:|
| **مالك** | ✓ | ✓ | ✓ | ✓ | ✓ |
| **مدير عام (admin)** | ✓ | ✓ | ✓ | ✓ | ✓ |
| **مدير المكتب (manager)** | ✓ | ✓ | ✓ | ✗ | ✗ |
| **محاسب** | ✓ | ✗ | ✓ | ✗ | ✗ |
| **مدخل بيانات (staff)** | ✓ | ✓ | ✗ | ✗ | ✗ |
| **مطّلع** | ✓ | ✗ | ✗ | ✗ | ✗ |

> ملاحظة: **الاستحقاقات (charges)** تُدار ضمن «البيانات» لأنها تُولَّد بتفعيل العقد؛ أما تسجيل **الدفعات وإصدار الفواتير** فضمن «المالية».

## نطاق العقارات
يمكن تقييد بعض الأعضاء (مثل مدير المحفظة) بـ **مجموعة عقارات بعينها** داخل المنشأة، فلا يرون غيرها. هذه طبقة حماية ثانية فوق عزل المنشآت.

## عزل البيانات (مهم)
- كل منشأة معزولة تماماً عن غيرها؛ لا تسريب بين عملاء متنافسين.
- إلغاء عضوية أي شخص **يقطع وصوله فوراً**.
- كل عملية حسّاسة تُسجَّل في **سجل تدقيق** غير قابل للتعديل (من فعل ماذا، في أي منشأة، وبأي صلاحية وقتها).

## إجراءات حسّاسة (تتطلب تحقّقاً إضافياً)
⏳ **قريباً:** بعض الإجراءات ستطلب رمز تحقق إضافياً (Step-up) لحمايتك، مثل:
- تغيير رقم الجوال.
- إدارة الأعضاء والصلاحيات.
- تعديل البيانات البنكية (الآيبان) للمالك.
- تصدير البيانات.

---

## دعوة عضو (قريباً)
سيتمكّن المالك/المدير من إرسال دعوة عبر رقم جوال العضو، مع تحديد دوره ونطاقه. الدعوة تُقبل برمز خاص، وتُنشأ العضوية فقط عند قبول الدعوة.
